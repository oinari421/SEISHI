精子レースゲーム 配布版
========================

【内容】
- index.html：画面構成とCSS
- script.js：ゲーム処理（JavaScript）
- vendor/peerjs/peerjs.min.js：ローカル対戦の通信に使うライブラリ
- vendor/peerjs/LICENSE.txt：通信ライブラリのライセンス

【一人で練習する】
1. index.html をダブルクリックしてブラウザで開きます。
2. タイトル画面で「一人で練習」を選びます。

【友人と対戦する】
ローカル対戦は、全員が同じ公開URLへアクセスできる状態が必要です。
ZIPを各自のPCで直接開くだけでは、招待コードによる別端末対戦が正常に
動かない場合があります。

1. このフォルダ一式をGitHub PagesなどのHTTPS対応サービスで公開します。
2. 全員が公開された同じURLを開きます。
3. ホストが「ローカル対戦」から部屋を作成します。
4. 表示された招待コードを友人へ送ります。
5. 友人がコードを入力して参加します。
6. ホストが対戦人数とCPU補充を設定して開始します。

【重要】
- フォルダ構成を変えずに公開してください。
- インターネット接続が必要です。
- 招待コード通信はPeerJSの公開シグナリングサービスを利用します。
- ファイアウォールやネットワーク環境によって接続できない場合があります。

【推奨ブラウザ】
- Google Chrome 最新版
- Microsoft Edge 最新版

更新日：2026年8月14日

【人数・通信ルール】
- 卵子数：2人=1個、3人=2個、4人=2個、5人=3個、6人=4個
- 得点：獲得順に3点、2点、1点、4個目も1点
- ゲスト切断：10秒後、同じP番号・得点・能力・位置のままCPUが代行
- ホスト切断：10秒後に試合を中断し、ロビーへ戻る
- 試合開始：全端末のマップ受信完了後、共通の開始時刻でカウントダウン
- 移動表示：自分は最新座標、相手は補間表示
- v4：ゲスト側でCanvasだけ空白になる状態コピー処理を修正
- v5：ゲスト自身の入力予測、相手の速度予測、通信詰まり時の古い状態破棄を追加
- v5：ホストのheartbeatを2.5秒監視し、切断時は10秒表示後にロビーへ戻る
- v6：相手の未来予測を廃止し、約100ms過去の2状態間を補間
- v6：自分はホストと同じ移動・壁・水流・粘液処理をローカル実行
- v6：自分の誤差15px未満は無視、15～60pxは0.2秒補正、60px超は即修正

【ラグ調整箇所（script.js上部）】
- NETWORK_SEND_MS：ホストの状態送信間隔（初期値33ms）
- MAX_BUFFERED_BYTES：送信待ちを破棄する基準（初期値64KB）
- REMOTE_INTERPOLATION_DELAY_MS：相手を何ms過去で補間するか（初期値100ms）
- LOCAL_IGNORE_ERROR_PX：自分の位置誤差を無視する範囲（初期値15px）
- LOCAL_SNAP_ERROR_PX：自分を即座にホスト位置へ戻す基準（初期値60px）
- LOCAL_CORRECTION_SECONDS：中程度の誤差を戻す時間（初期値0.2秒）
- HOST_SILENCE_MS：ホスト無通信を切断と判断する時間（初期値2500ms）
【タックル操作】
Spaceキーまたは画面下のTACKLEボタンで、向いている方向へ突進します。
タックルはダッシュと統合されており、移動と攻撃を兼ねます。
正面同士は相打ち、側面・背後から当てるほど強く吹き飛ばします。
空振りすると0.65秒硬直し、再使用まで基本2秒かかります。
連続で攻撃を受けると「ふらつき」が増え、より遠くへ飛ばされます。

【マップ】
ゲームごとに「標準子宮」「迷路子宮」「激流子宮」から1つ選ばれます。
マップ画面表示後、マップ名と特徴を2秒表示し、3→2→1→STARTで開始します。
3ラウンド中は同じマップを使い、卵子の位置だけ毎ラウンド変わります。
通行可能範囲は、膣口から子宮頸部、子宮腔、左右の卵管口を参考にした形です。
