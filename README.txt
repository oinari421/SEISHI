精子レースゲーム 配布版
========================

【内容】
- index.html：画面構成とCSS
- script.js：ゲーム処理（JavaScript）
- vendor/peerjs/peerjs.min.js：ローカル対戦の通信に使うライブラリ
- vendor/peerjs/LICENSE.txt：通信ライブラリのライセンス

【一人で練習する】
1. index.html をダブルクリックしてブラウザで開きます。
2. タイトル画面で「一人で練習」を選びます。

【友人と対戦する】
ローカル対戦は、全員が同じ公開URLへアクセスできる状態が必要です。
ZIPを各自のPCで直接開くだけでは、招待コードによる別端末対戦が正常に
動かない場合があります。

1. このフォルダ一式をGitHub PagesなどのHTTPS対応サービスで公開します。
2. 全員が公開された同じURLを開きます。
3. ホストが「ローカル対戦」から部屋を作成します。
4. 表示された招待コードを友人へ送ります。
5. 友人がコードを入力して参加します。
6. ホストが対戦人数とCPU補充を設定して開始します。

【重要】
- フォルダ構成を変えずに公開してください。
- インターネット接続が必要です。
- 招待コード通信はPeerJSの公開シグナリングサービスを利用します。
- ファイアウォールやネットワーク環境によって接続できない場合があります。

【推奨ブラウザ】
- Google Chrome 最新版
- Microsoft Edge 最新版

【タックル操作】
Spaceキーまたは画面下のTACKLEボタンで、向いている方向へ突進します。
タックルはダッシュと統合されており、移動と攻撃を兼ねます。
正面同士は相打ち、側面・背後から当てるほど強く吹き飛ばします。
空振りすると0.65秒硬直し、再使用まで基本2秒かかります。
連続で攻撃を受けると「ふらつき」が増え、より遠くへ飛ばされます。

【マップ】
ゲームごとに「標準子宮」「迷路子宮」「激流子宮」から1つ選ばれます。
マップ画面表示後、マップ名と特徴を2秒表示し、3→2→1→STARTで開始します。
3ラウンド中は同じマップを使い、卵子の位置だけ毎ラウンド変わります。
通行可能範囲は、膣口から子宮頸部、子宮腔、左右の卵管口を参考にした形です。
